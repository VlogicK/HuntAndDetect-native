# HuntAndDetect-native

A parallel Detection-as-Code implementation for Microsoft Sentinel using the native **Microsoft Sentinel Repositories** integration.

This repository complements [HuntAndDetect](https://github.com/VlogicK/HuntAndDetect), which uses a custom YAML validation, conversion, GitHub Actions, OIDC, and REST deployment pipeline. The goal here is to implement the same detection-as-code idea with Sentinel's platform-native repository workflow and compare the operational trade-offs.

## Initial scope

- Store Microsoft Sentinel analytics rules as Bicep.
- Connect this repository to a dedicated Sentinel lab workspace.
- Let Microsoft Sentinel create and manage the repository deployment workflow.
- Observe native smart deployment behaviour.
- Compare the native flow with the custom HuntAndDetect pipeline.

## Repository structure

```text
Detections/
└── Persistence/
    └── hijacking_text_file_associations.bicep
```

Additional Sentinel content types can be added later, including hunting queries, automation rules, parsers, playbooks, and workbooks.

## Deployment model

```text
Bicep content in GitHub
        ↓
Microsoft Sentinel repository connection
        ↓
Sentinel-managed GitHub workflow
        ↓
Native content deployment
        ↓
Microsoft Sentinel workspace
```

The first rule is a Bicep version of the `Hijacking Text File Associations` detection from the original HuntAndDetect project.

## Current status

The initial analytics rule is ready. The next step is to connect this repository to a dedicated Microsoft Sentinel workspace and inspect the workflow generated by Sentinel.
